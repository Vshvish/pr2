# Инструкция по тестированию программы

## Быстрая проверка работы

### 1. Тест основной функциональности
Запустите программу с известным пакетом:
```bash
python src/main.py --package Newtonsoft.Json --version 13.0.1 --source https://api.nuget.org/v3/index.json
```

**Ожидаемый результат:**
- Выводится список зависимостей без дубликатов
- Каждая зависимость показывается только один раз

### 2. Автоматические тесты
Запустите набор тестов:
```bash
python test_dependencies.py
```

Тесты проверяют:
- ✅ Базовая функциональность
- ✅ Удаление дубликатов
- ✅ Обработка несуществующего пакета
- ✅ Обработка несуществующей версии
- ✅ Пакеты без зависимостей

## Примеры тестовых случаев

### Пакет с зависимостями
```bash
python src/main.py --package Newtonsoft.Json --version 13.0.1 --source https://api.nuget.org/v3/index.json
```

### Пакет без зависимостей
```bash
python src/main.py --package System.Runtime.CompilerServices.Unsafe --version 6.0.0 --source https://api.nuget.org/v3/index.json
```

### Проверка обработки ошибок (несуществующий пакет)
```bash
python src/main.py --package NonExistentPackage12345 --version 1.0.0 --source https://api.nuget.org/v3/index.json
```

### Проверка обработки ошибок (несуществующая версия)
```bash
python src/main.py --package Newtonsoft.Json --version 999.999.999 --source https://api.nuget.org/v3/index.json
```

## Что проверять

1. **Корректность вывода**: зависимости выводятся в формате `- ИмяПакета [версия]`
2. **Отсутствие дубликатов**: каждая зависимость показывается только один раз
3. **Обработка ошибок**: при неверных данных выводится понятное сообщение об ошибке
4. **Работа с разными пакетами**: программа работает с любым пакетом из NuGet

## Исправленные проблемы

✅ **Дубликаты зависимостей** - исправлено: теперь каждая зависимость показывается только один раз
✅ **Поиск версий** - исправлено: программа корректно ищет версии в структуре NuGet API v3
